## Decisions already approved (don't ask again)
- English-only for beta 1.0. Word counts use whitespace splitting.
- Supabase runs locally (Supabase CLI + Docker), starting in Phase 4.
- The worker claims jobs through a SQL function `claim_next_job()` (FOR UPDATE SKIP LOCKED),
  called with supabase `rpc`, not through a direct Postgres connection.
- Finding chapters: use the file's own structure first (EPUB spine/TOC, PDF bookmarks),
  then the chapter titles from the book check, then split by paragraphs.
- Resume safety: save the whole chunk plan as `pending` chunk rows before summarizing starts.
  The book check runs once per book and its result is stored.
- Prompts: the stray "(e.g. ...)" line in `2_chunk_summary.txt` was removed (approved).
  For `3_final_summary.txt`, the code sends only the FICTION or LEARNING half, cut at the
  `=== IF ... ===` markers. The file itself stays whole.
- Token budget = LLM_CONTEXT_TOKENS minus a reserve for the answer: 2500 for chunk/merge calls
  (LLM_ANSWER_RESERVE_TOKENS), 4500 for the final call (LLM_FINAL_ANSWER_RESERVE_TOKENS).
- Fill placeholders by plain string replacement of known names, never `str.format()`.
- Book title and author come from file metadata, falling back to the filename and "Unknown".

## Environment facts (verified)
- Use `python3.11`. Plain `python3` on this Mac is 3.8. Venv: `backend/.venv`.
  Run backend commands from `backend/`: `source .venv/bin/activate`, then `pytest` or
  `python -m pipeline.check_llm`.
- Ollama 0.40.1 runs as a Homebrew service. Model: `qwen2.5:14b`. Mac: M1 Max, 32 GB.
- Ollama's OpenAI-compatible `/v1` endpoint IGNORES `num_ctx`; the native `/api/chat` honors it.
  By default this Mac loads a 32768-token context. `check_llm` checks that the loaded
  context is >= LLM_CONTEXT_TOKENS.
- The `openai` package is 3.x (pinned `<4`) and depends on `httpx2`, not `httpx`. Don't import
  `httpx`; use the openai client or `urllib`.
- For JSON mode, use `response_format={"type": "json_object"}`.
- Supabase CLI 2.120 (Homebrew) + OrbStack for Docker. `supabase start` from the project root; realtime,
  edge runtime, and analytics are turned off in `supabase/config.toml`. Local keys are in `backend/.env`
  (the legacy JWT `ANON_KEY` / `SERVICE_ROLE_KEY` from `supabase status -o json`).
- Port 8000 on this Mac is often taken by another of the user's projects (a uvicorn server). Don't kill it;
  test Kru's API on another port (e.g. 8010).
- `supabase` (Python) installs `httpx`; the "don't import httpx" rule above still applies to our own code.
